ForzaStudio EVO 0.0.4 - BETA
============================

ForzaStudio EVO is a modding tool for the Xbox 360 Forza games (FM4, FH1, FH2;
FM2 and FM3 partly). It edits the game files in place: car models (.carbin),
textures (.xds), XML files and the game database. It also ports cars from
Forza Horizon 1 and 2 and Forza Motorsport 2 and 3 to Forza Motorsport 4, as
a DLC package for Xenia or a modded (RGH/JTAG) Xbox 360.

THIS IS AN EARLY BETA. Expect bugs. Work on a COPY of your game folder,
never on your only copy.

The full manual is MANUAL.md (open it with any text editor or a Markdown viewer).


1. WHAT YOU NEED
----------------
- Windows 10 or 11.
- .NET Framework 4.8 (already part of Windows 10 and 11).
- Microsoft XNA Framework Redistributable 3.1 (for the 3D view). If its
  installer asks for .NET Framework 3.5: Control Panel > Programs >
  Turn Windows features on or off > ".NET Framework 3.5 (includes .NET 2.0
  and 3.0)".
- An extracted copy of the game (the folder holding default.xex and Media).
- For DLC packages: Xenia Canary.
- The files below. They are NOT in this zip: they belong to others and
  cannot be shared. Bring your own and put them exactly here (paths are
  from the folder that holds ForzaStudioEVO.exe):

  File                                   Where                       Needed for
  -------------------------------------  --------------------------  ---------------------------------
  xcompress.dll (Xbox 360 SDK)           next to ForzaStudioEVO.exe  opening and saving the game's
                                                                     compressed zips: almost everything
  xds.dll (from the Forza Studio 4.6     next to ForzaStudioEVO.exe  textures (.xds): view, import,
  release)                                                           export, thumbnails
  xma2encode.exe (Xbox 360 SDK,          xma2encode\xma2encode.exe   Add Song (your own music in FM4)
  bin\win32)
  TireAOffroad.zip, TireBOffroad.zip,    Service\OffroadTires\       the "Offroad" tire choice of the
  TireCOffroad.zip                                                   car port
  TireASmall.zip, TireBSmall.zip,        Service\SmallTires\         the "Small" tire choice of the
  TireCSmall.zip (FM4's TireA/B/C                                    car port

  Without one of them, the features in its row do not work.

Everything else is already in this zip, next to ForzaStudioEVO.exe.
Keep the files together: do not move ForzaStudioEVO.exe out of its folder.


2. INSTALL
----------
1. Unzip the whole folder anywhere you can write to (for example the Desktop,
   not Program Files).
2. Run ForzaStudioEVO.exe.

ForzaStudio EVO writes only inside its own folder:
- ForzaStudio.ini   your folders and all the options
- bak\              a copy of every file before it is overwritten
                    (switch off with Enabled = off under [Backup] in the ini)
Work folders go to %TEMP%\ForzaStudio (the program cleans them; safe to delete).


3. FIRST STEPS
--------------
- File > Open Folder...   pick the game folder (the one with Media).
  The tree loads as you expand it. Double-click a .zip to open it.
- File > Open Archive...  open one .zip, gamedb.slt or .xds directly.
- Click a file in the tree to view it: .carbin (3D model), .xds (texture),
  .xml/.ini/.txt (text editor), gamedb.slt (database), .fbf (digital dash).
- Edits are kept in memory (shown with * in the tree) until File > Save.
  Every save first copies the old file into bak\.
- Ctrl+B (or Alt+Left) goes back to where you were.


4. PORT A CAR FROM FORZA HORIZON TO FM4 (DLC FOR XENIA)
-------------------------------------------------------
Tools > Create DLC Package...   (Tools > Import Car From Another Forza... writes
into the game's own files instead)

1. Set the source folder (Forza Horizon 1 or 2, or Forza Motorsport 2 or 3) and the
   Forza Motorsport 4 folder,
   then press Load Cars.
2. Select a car, choose its FM4 donor (a star = closest match),
   press Add -> between the two lists (or double-click the car). Repeat for every car you want.
3. Give the pack a Name.
4. Press Trial Pack. Nothing is written to the game yet.
   Check the Review column and the Review tab; choose fixes if needed,
   then run Trial Pack again.
5. Set Xenia's folder (the one with xenia_canary.exe).
6. CLOSE XENIA, then press Build DLC Package.
7. Start FM4 in Xenia: the cars are listed under their makes, like any other car.

Several packs can be installed together. Cars can be added to a built pack
later (Add To Package...) or taken out (File > Delete Car from DLC Package...),
and Tools > Check and Validate DLC... checks a pack without changing it.

Use an FM4 folder where these cars were never installed with
"Install In FM4": an old install hides the pack's version of the car.


5. KNOWN PROBLEMS IN THIS BETA
------------------------------
EXPERIMENTAL (not tested in game, use on a copy):
- Digital dash: changing a value in place works; Duplicate, Delete, Add and
  "Texts from another car's dash" are NOT tested in game.
- Models rebuilt from OBJ, OBJ onto wheel zips, "Merge Into".
  FBX export/import: checked with 3ds Max, Blender and in game; glTF
  export/import: checked with ZModeler 2 (glTF filter) and in game.
- A new country added with a new make in a pack.
- Add song needs xma2encode (Xbox 360 SDK, not included).

KNOWN LIMITS:
- Engine swaps whose sound is on FM4's second disc can crash a race.
- The hex view of the classic window (Tools > Pay Respects) only works
  after a model was opened in that window.
- FM2 models can be exported but not imported back.
- FM3 models can be viewed but not edited (the port tool converts them).
- FM3 digital dashes are converted (checked on one car): please report what you see.
- For a real Xbox 360, the window's Build for Xbox 360... writes the package;
  copying it to the console (FTP) is up to you.


6. REPORTING A BUG
------------------
Please send:
- what you did, step by step, and what happened;
- a screenshot of any error message;
- for a car port: the car, the donor, and port_log.txt (inside the
  converted car zip, or in the Report tab of the port window).

Send reports to: https://github.com/FMdangaina/ForzaStudio-EVO/issues
(one issue per problem; attach screenshots and port_log.txt there).
